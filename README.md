# Demo Standard

Reusable demo app for ERPNext/Frappe sites.

What it includes:

- consolidated Arabic translations
- bundled Arabic font for desk and web
- lightweight desk polish for RTL demos
- curated demo workspace
- automatic workspace ordering on install/migrate

What it intentionally avoids:

- client-specific branding
- company data
- website settings tied to an old demo
- industry-specific fixtures
